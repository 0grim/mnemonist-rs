# `ranks[x_root]/[y_root]` where upstream reads `ranks[x]/[y]`. That makes the
# port strictly more correct than upstream -- and therefore wrong, because the
# elected root is observable through `find`. The fuzzer found it in 129 cases
# and shrank a 600-op program to the three operations that matter:
#
#     var s = new StaticDisjointSet(23);
#     s.union(10, 7);            // ranks[10] stays 0; ranks[7] never set
#     s.union(11, 7);            // upstream: 0 == 0, so root becomes 11
#     s.find(10);                // upstream 11, rank-correct port 10
#
# The sabotage was reverted and this seed now passes. It stays checked in as a
# regression guard: if anyone ever "cleans up" the reproduced rank bug, this
# exact case fails again before any novel case is generated.
#
